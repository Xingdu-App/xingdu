# 适配器边界

运行时已在 `internal/protocol` / `internal/agent` 实现 sing-box 的五种 TLS 协议部署。客户端适配器位于 `internal/subscription`，包含 Stash、Mihomo、Surge、Loon 和 Hysteria 2 URI；各格式的支持范围及证书限制见 [订阅说明](SUBSCRIPTIONS.md)。实际 App 验收仍待完成。以下描述保留完整目标边界，版本化更新与回滚尚待实现。

## 运行时适配器

输入是版本化的服务与线路规格，职责包括能力声明、参数校验、配置渲染、引擎自检与服务操作计划。渲染过程不直接执行远程命令。主机操作由 Agent 执行，任务状态和版本由控制端维护。

配置计划需要包含引擎版本、受管理文件、监听端口、服务依赖、验证步骤与恢复策略。未知或不支持的协议组合应报错，不能静默降级。

## 客户端适配器

输入是统一节点模型和目标客户端版本，输出配置及不可兼容项的明确原因。不同客户端的订阅格式分别实现；不以一个客户端的 YAML 格式作为领域模型。

客户端适配器不持有云厂商或 SSH 凭据。节点访问凭据只在授权的配置输出边界中解析，不能写入普通日志。

## 验证

每个被宣称支持的组合须记录引擎版本、协议及传输参数、客户端版本、真实导入及连通结果。编译、渲染成功和端口开放不能代替端到端验证。
