# SaaS 开放前检查清单

Xingdu Cloud 已正式上线，付费套餐使用 Stripe 正式支付。本清单区分页面已补齐的内容与仍需运营决策、部署验证的事项，
不能作为正式上线验收记录。不得仅因代码合并、容器健康或付款接口存在而标记完成。

上线状态不表示本清单所有验收项目均已完成；未附证据的项目保持待核验。

- [x] 联系渠道：`info@xingdu.app`，用于支持与隐私咨询。
- [ ] 验证该邮箱收发、负责人、值班安排及敏感请求的身份核验流程。
- [ ] 填写实际运营主体、所在地区、联系信息；按实际运营地区完成条款审阅。

`/service` 是当前功能和使用边界说明，不是已审核的正式 SaaS 合同。
不要在注册按钮旁声明用户同意一份尚未发布的服务条款。

## 套餐与收款

- [ ] 核准当前页面的 Starter $5/月、$40/年、10 台服务器及 Premium $20/月、$200/年、50 台服务器，与实际支付价格一致；
      补齐明确币种与含税说明，确认其余资源额度。
- [ ] 明确试用、扣款时间、自动续费、取消生效时间、退款和欠费处理规则。
- [ ] 区分「客户端订阅」与「付费套餐」，避免用户误解订阅链接产生费用。
- [ ] 验证支付成功/失败/取消、重复回调、回调延迟、续费失败、取消续费及恢复。
- [ ] 核对收费页面、支付平台与实际配额一致；确认账单及支付相关数据的隐私说明。
- [ ] 完成上述事项后，检查官网、控制台和支付平台的开放状态说明一致。

不要将未验收的支付实现直接描述成已经开放的付费服务。

## 公网与账户验收

- [ ] 验证正式域名、HTTPS、Cookie 安全属性、代理和健康检查。
- [ ] 使用真实邮件完成注册、验证码过期与重发验收；验证邮件不会泄漏敏感信息。
- [ ] 对已启用的第三方登录验证授权、回调、已验证同邮箱自动关联、不同邮箱不自动合并。
- [ ] 验证邀请接受/过期/撤销、跨组织隔离、各角色权限及配额到限行为。
- [ ] 验收已实现的邮箱找回密码流程，包括验证码、密码重置、旧会话失效和通知投递；明确无法访问邮箱时的人工恢复方案。
- [ ] 验证移动端首页、帮助、隐私、登录和控制台；检查中英文错误与空状态。
- [ ] 检查所有公开链接、站点地图、未知路径 404 和控制台禁止索引。

## 运维与实际连接验收

- [ ] 在目标 VPS / 系统 / 架构上完成 Agent 安装、心跳、部署、重启和卸载。
- [ ] 按 [客户端矩阵](SUBSCRIPTIONS.md) 逐个记录实际 App 版本、导入、
      TLS 错误拒绝、TCP/UDP 转发、更新与撤销结果。
- [ ] 确认证书到期处理流程；自动证书进程未配置或实测前不得承诺自动处理。

- [ ] 验证告警与事故响应渠道、日志脱敏、密钥保管与轮换流程。

验收记录应包含日期、版本、环境、执行人、结果与脱敏证据。
不要把真实服务器地址、凭据、私人路径或原始日志提交到仓库。
