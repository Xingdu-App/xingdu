# 配置版本、中转与外部探测

本轮为开发预览实现，不代表公网发布验收。节点更新要求 Agent 0.12.0-dev；
先升级 Agent 并等待新版本心跳。现有旧 Agent 的原协议部署不受此门槛影响。

## 编辑与恢复

在节点详情选择「编辑 / 版本恢复」，可修改名称、端口、TLS 域名，替换证书
和私钥，或重新生成连接凭据。协议类型不能原地改变，应创建新节点并迁移
订阅。证书/私钥留空表示保留，私钥不会回显。提交前需要确认短暂连接中断。

服务端保存加密历史和候选配置；只有 Agent 成功确认后才更新活动配置。
Agent 校验候选配置、保存本地旧配置、重启并检查进程。启动失败时恢复旧配置
并再次启动。回滚失败、执行中断或确认丢失属于结果不确定，不自动重复执行，
也不继续叠加修改；需核实机器状态或卸载后重新部署。进程检查不是公网探测。

历史恢复创建一个新的配置版本。已过期证书不能恢复；轮换凭据后旧客户端
失效，恢复包含旧凭据的版本会重新启用这些凭据。修改端口、证书或凭据后，
需要客户端刷新订阅。订阅令牌撤销不能撤销已下载的节点凭据。

## 直连与单层中转

在「线路」选择已部署的入口和另一台服务器上的出口，确认应用。客户端仍
使用入口节点订阅；服务端将 TCP 流量转发到出口，不会在出口故障时自动切回
入口直连。两端端口、防火墙与链路需要可达；不保证比直连更快。

出口必须是直连节点，不接受同机中转、链式中转或跨组织节点。入口使用出口
的客户端凭据和公开证书，不获得出口 TLS 私钥或机器身份。出口地址按运营者
的网络策略解析并固定 IP，不在运行时重新解析用户指定的出口主机名。私网
实验出口需运营者明确配置允许网段，租户不能自行放行。

出口被使用或正在应用为某线路的出口时，不能修改/卸载出口或删除、修改其
服务器。先取消中转或切换出口并等待确认，再维护原出口。自动续期也遵守这个
保护；当前不会自动协调整组依赖节点的证书切换。入口的私网目标限制仍有效。
单层中转目前仅转发 TCP，即使入口/出口使用 QUIC，也不代表支持代理 UDP。

## 独立外部探测

构建 `go build -o bin/xingdu-probe ./cmd/probe`，在独立网络的探测机运行。
部署者配置下列环境变量，API Key 不放在命令参数或 Git 中：

```ini
XINGDU_PROBE_API=https://control.example.com
XINGDU_PROBE_ORG=组织ID
XINGDU_PROBE_API_KEY=待替换
XINGDU_PROBE_RUNTIME=/opt/xingdu/sing-box
XINGDU_PROBE_ENDPOINT=https://probe.example.com/ip
```

使用仅含 `nodes:read`、`nodes:credentials`、`nodes:probe` 的可撤销 API Key。
运行时必须与仓库固定的架构/SHA-256 匹配。探测目标由运营者设定，必须是
返回纯文本出口 IP 的 HTTPS 服务，不接受租户自定义探测 URL。不跟随重定向。
探测机需要访问公网节点，默认拒绝私有或保留地址。仅隔离实验或受控管理网
可由运营者设置 `XINGDU_PROBE_ALLOWED_CIDRS`（逗号分隔），租户不能修改。

程序每轮逐个节点建立真实代理连接，请求探测目标，记录结果、HTTP 请求耗时
及出口 IP，再等待一分钟。耗时不是 ICMP 延迟。运行时配置经 stdin 传送，
不将凭据传入参数，也不向子进程传入 API Key 环境变量。节点配置版本变化后
拒收旧结果。界面将三分钟以上的结果标为过期；本机服务状态另行显示。

探测目前为运营者部署的组织级进程，不是默认启用的全球探测平台；未配置
进程时显示未探测。告警通知投递和多探测点调度仍需另行接入。

## 本地验证范围

在隔离 Linux 容器和 Android 客户端中验证了 Shadowsocks TCP 转发、
入口到出口的单层中转、取消中转、出口依赖保护、凭据轮换和历史恢复。
节点端口修改与历史端口恢复后，分别再次通过真实连接。
这些结果不涵盖公网 VPS、防火墙、UDP 或所有客户端版本与协议组合。

独立探测核心使用固定 SHA-256 的真实运行时，经协议节点发起 HTTPS 请求、
验证证书并读取目标观察到的源地址；错误节点凭据被拒绝。这证明协议探测
路径，不等同于独立公网探测机或线上 API Key 调度进程验收。存储测试覆盖
结果上报与配置版本冲突。

SS2022、AnyTLS、HTTPS 和 QUIC 的 Android 客户端组合尚未完成验收，
不列为已验证兼容；不会通过放宽证书校验来满足兼容要求。

验证命令：`make check`、独立 PostgreSQL 的 storage/httpapi race 测试、
`docker compose up --build -d --wait`（另加载本地 Agent lab 配置）均通过。
自动证书使用模拟 ACME 服务验证订单、DNS challenge、清理和私有状态文件；
未调用真实 DNS 提供商或公共 CA，未执行真实支付或发送注册邮件。
