## 已验证

- PostgreSQL 使用非 owner 运行角色：跨租户权限、配额并发、密码与会话隔离、所有权转移的并发一致性。
- 本地 Ubuntu Agent 0.6：保留原机器身份，服务停止被报告为 inactive，API 重启后恢复 active，Hysteria 2 真实 TLS/QUIC 转发及私网出口拒绝；未卸载演示节点。
- 客户端导出单元测试：不支持的协议拒绝、证书固定、公有 CA 校验、URI 转义与规则限制。这不是实际 App 验收。
- 全新隔离测试库从零应用迁移，并通过 `make check`（Go race、后端集成、前端 lint/build）。
- 加密备份已验证篡改/截断拒绝及一次性数据库恢复；生产全库恢复仍需专门演练。
- 详细工具验证与运行说明分别见 [节点生命周期](NODE-LIFECYCLE.md)、[订阅](SUBSCRIPTIONS.md)、[账户安全](ACCOUNT-SECURITY.md)、[运维](OPERATIONS.md)、[备份](BACKUP.md)。

## 下一阶段验收顺序

1. 建立证书和配置版本模型，再实现 ACME/续期、配置修改、回滚，避免证书与节点状态分离后无法恢复。
2. 加入受限的外部协议探测 Worker，探测结果与本地服务状态分别展示；明确通知渠道后接入投递。
3. 实际 App 兼容验收与 Shadowrocket 格式，不通过跳过证书校验凑兼容数量。
4. 邮件与 MFA、组织销毁、密钥轮换及跨实例限流，再进行公网隔离部署和恢复演练。

Zeabur 预览部署的步骤与配置见 [部署说明](ZEABUR.md)。Resend 使用占位 Key 时注册不可用；真实邮件投递、ACME、付费服务和生产密钥轮换不属于已验证能力。
